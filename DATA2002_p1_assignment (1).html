1 Introduction

This report examines how paid employment and study habits relate to students’ university experience, using survey data from DATA2002/2902 students. Three research questions investigate these relationships, with limitations including self-reported data and sampling bias.

2 Data Wrangling

All data processing for this report was conducted in R (R Core Team, 2026) within the R Markdown environment (Xie, Allaire, & Grolemund, 2018) for reproducibility. Data wrangling was performed using base R and the tidyverse, and visualisations were produced with ggplot2 (Wickham et al., 2019).

Variables were cleaned and recoded, with missing values handled case-by-case. The survey dataset was imported, variables were renamed for clarity, “Other” responses were removed from assess, and work_hrs values above 70 hours per week were removed because they exceed a standard full-time work week. A boxplot compares the distributions before and after cleaning, and the cleaned data are saved as survey_cleaned.csv.

Figure 2 confirms strong right-skew and zero-inflation, so normality cannot be assumed; we use the Wilcoxon rank-sum test instead.

1. Hypotheses:

Let \(\theta_1\), \(\theta_2\) denote population median weekly work hours for Cram (Yes) and Non-Cram (No) students.

\(H_0: \theta_1 = \theta_2\)
\(H_1: \theta_1 \neq \theta_2\)

2. Assumptions:

Samples are independent. Interpreting a difference as a median shift requires similarly shaped distributions: both groups show comparable skewness and zero-proportions (Table 2), supporting this. Heavy tying at zero makes the exact null distribution unavailable, so a normal approximation with continuity correction is used.

Code 
cram_raw <- rq1_data %>% filter(is_cram == "Yes") %>% pull(work_hrs)
noncram_raw <- rq1_data %>% filter(is_cram == "No") %>% pull(work_hrs)

manual_skew <- function(x) {
  n <- length(x)
  m <- mean(x)
  (sum((x - m)^3) / n) / (sum((x - m)^2) / n)^(3/2)
}

tibble::tibble(
  Group = c("Yes", "No"),
  Skewness = round(c(manual_skew(cram_raw), manual_skew(noncram_raw)), 2),
  `% zero` = round(c(mean(cram_raw == 0), mean(noncram_raw == 0)) * 100, 1)
) %>%
  knitr::kable(align = c("l", "c", "c"))

3. Test statistic:

Code 
wilcox_test <- wilcox.test(cram_raw, noncram_raw, exact = FALSE, correct = TRUE)

tibble::tibble(
  Statistic = round(unname(wilcox_test$statistic), 1),
  p_value = format.pval(wilcox_test$p.value, digits = 3, eps = 0.001)
) %>%
  knitr::kable(align = c("c", "c"))

R reports the Mann-Whitney statistic; observed \(w = 3.7831\times 10^{4}\), giving \(p = <0.001\) (Table 3).

Code 
n1 <- length(cram_raw)
n2 <- length(noncram_raw)
r_rb <- 1 - (2 * unname(wilcox_test$statistic)) / (n1 * n2)

4. P-value:

Since \(p = 0.000458 < 0.05\), we reject \(H_0\). The rank-biserial effect size is \(r = -0.189\), indicating a small effect with Cram students tending toward higher work hours.

5. Decision:

Since \(p = 0.000458 < 0.05\), we reject \(H_0\): Cram students report significantly higher weekly work hours. Ties at zero reduce the precision of the rank-based test, though the large sample size still supports the conclusion. As this is observational data, the result reflects association, not causation, and unmeasured confounders (e.g., course load, financial need) remain possible.

3.2 RQ2: Multitasking and cramming

Research Question: Is multitasking during lectures associated with cramming before assessments?

Our client, a university learning-support team, wants to distinguish a lecture-engagement problem from a broader time-management one. Divided attention during study has been linked to weaker academic outcomes (Junco & Cotten, 2012), so multitasking is unlikely to be a neutral habit. If it also travels with cramming, the two may be one behavioural pattern rather than two, which we test with a chi-squared test of independence.

Exploratory data analysis:

Rows are dropped only for missing assess or multitask; the work_hrs threshold is not applied here, as neither variable involves paid employment.

4. P-value: \(P(\chi^2_{1} \geq 20.05) = 7.55\times 10^{-6}\). Cramér’s \(V = 0.17\) (\(n = 664\)), and the 95% CI for the difference in multitasking rates is 13.7 to 31.5 percentage points.

welch_stat <- function(hours, group) {
  hours_yes <- hours[group == "Yes"]
  hours_no  <- hours[group == "No"]

  (mean(hours_yes) - mean(hours_no)) /
    sqrt(var(hours_yes) / length(hours_yes) +
           var(hours_no) / length(hours_no))
}

mean_yes <- mean(rq3_data$work_hrs[rq3_data$multitask == "Yes"])
mean_no  <- mean(rq3_data$work_hrs[rq3_data$multitask == "No"])
mean_difference <- mean_yes - mean_no
t_observed <- welch_stat(rq3_data$work_hrs, rq3_data$multitask)

set.seed(2002)
B <- 10000

t_permuted <- replicate(
  B,
  welch_stat(
    rq3_data$work_hrs,
    sample(rq3_data$multitask, replace = FALSE)
  )
)

n_yes <- sum(rq3_data$multitask == "Yes")
n_no  <- sum(rq3_data$multitask == "No")
sd_yes <- sd(rq3_data$work_hrs[rq3_data$multitask == "Yes"])
sd_no  <- sd(rq3_data$work_hrs[rq3_data$multitask == "No"])
pooled_sd <- sqrt(
  ((n_yes - 1) * sd_yes^2 + (n_no - 1) * sd_no^2) /
    (n_yes + n_no - 2)
)
cohens_d <- mean_difference / pooled_sd

1. Hypotheses: Let \(\mu_Y\) and \(\mu_N\) be the population mean weekly paid-employment hours for students who do and do not multitask, respectively. \(H_0: \mu_Y - \mu_N = 0\) versus \(H_1: \mu_Y - \mu_N \neq 0\).

2. Assumptions: Student responses are treated as independent, and the multitasking labels are exchangeable under \(H_0\). Normality is unnecessary, although a mean-based statistic remains sensitive to large values.

3. Test statistic: \(T=(\bar X_Y-\bar X_N)/\sqrt{S_Y^2/n_Y+S_N^2/n_N}\). The observed difference is 1.79 hours per week and \(t_0=2.172\).

4. Permutation procedure: With set.seed(2002), the Yes/No labels were shuffled \(B=10{,}000\) times while employment hours were fixed. The Welch statistic was recalculated to form Figure 5.

5. P-value: For the two-sided test, permutations satisfying \(|T_b^*|\geq|t_0|\) were counted. The plus-one estimate is \(p_{\mathrm{perm}}=0.0317\).

6. Decision: Since \(p = 0.0317 < 0.05\) (the p-value uses the plus-one correction of Phipson & Smyth, 2010), we reject \(H_0\). There is evidence that mean employment hours differ by multitasking status; multitasking students worked 1.79 more hours per week on average in this sample. However, Cohen’s \(d=0.17\) indicates a small effect, so its practical importance is limited. Both variables are self-reported and confounding may remain. As this is an observational survey of students, the result cannot establish causation or automatically generalise to others.

4 Conclusion

Overall, the three analyses show consistent links between students’ employment commitments and study behaviours. Students who crammed reported significantly higher weekly paid-employment hours, while multitasking was associated with both cramming and higher employment hours. However, the observed effects were modest, suggesting these factors are related but not decisive.

These findings may help the teaching team recognise how students’ external commitments and study habits interact, particularly when considering cramming and lecture multitasking.

However, the survey is observational and relies on self-reported data, limiting causal interpretation. The 70-hour cleaning threshold and categorisation of preparation styles may also affect results. Potential confounding factors, such as workload or other commitments, and voluntary sampling may limit generalisability. Therefore, the findings should be interpreted as associations rather than evidence of causation.

## RQ1: Work hours and cramming

**Research Question:** Is there a difference in weekly paid employment hours between students who cram before assessments and those who do not?

Paid employment may shape assessment preparation (Kember, 1999). We compare work hours between students who cram and those who do not, using the Wilcoxon rank-sum test.

**Exploratory data analysis:**

@fig-rq1-eda confirms strong right-skew and zero-inflation, so normality cannot be assumed; we use the Wilcoxon rank-sum test instead.

**1. Hypotheses:**

Let $\theta_1$, $\theta_2$ denote population median weekly work hours for Cram (Yes) and Non-Cram (No) students.

$H_0: \theta_1 = \theta_2$  
$H_1: \theta_1 \neq \theta_2$

**2. Assumptions:**

Samples are independent. Interpreting a difference as a median shift requires similarly shaped distributions: both groups show comparable skewness and zero-proportions (@tbl-rq1-skewness), supporting this. Heavy tying at zero makes the exact null distribution unavailable, so a normal approximation with continuity correction is used.

```{r}
#| label: tbl-rq1-skewness
#| tbl-cap: "Skewness and proportion of zero responses by cramming status."

cram_raw <- rq1_data %>% filter(is_cram == "Yes") %>% pull(work_hrs)
noncram_raw <- rq1_data %>% filter(is_cram == "No") %>% pull(work_hrs)

manual_skew <- function(x) {
  n <- length(x)
  m <- mean(x)
  (sum((x - m)^3) / n) / (sum((x - m)^2) / n)^(3/2)
}

tibble::tibble(
  Group = c("Yes", "No"),
  Skewness = round(c(manual_skew(cram_raw), manual_skew(noncram_raw)), 2),
  `% zero` = round(c(mean(cram_raw == 0), mean(noncram_raw == 0)) * 100, 1)
) %>%
  knitr::kable(align = c("l", "c", "c"))
```

**3. Test statistic:**

```{r}
#| label: tbl-rq1-wilcox
#| tbl-cap: "Wilcoxon rank-sum test comparing weekly paid employment hours by cramming status."

wilcox_test <- wilcox.test(cram_raw, noncram_raw, exact = FALSE, correct = TRUE)

tibble::tibble(
  Statistic = round(unname(wilcox_test$statistic), 1),
  p_value = format.pval(wilcox_test$p.value, digits = 3, eps = 0.001)
) %>%
  knitr::kable(align = c("c", "c"))
```

R reports the Mann-Whitney statistic; observed $w = `r round(unname(wilcox_test$statistic), 1)`$, giving $p = `r format.pval(wilcox_test$p.value, digits = 3, eps = 0.001)`$ (@tbl-rq1-wilcox).

```{r}
#| label: rq1-effect-size

n1 <- length(cram_raw)
n2 <- length(noncram_raw)
r_rb <- 1 - (2 * unname(wilcox_test$statistic)) / (n1 * n2)
```

**4. P-value:**

Since $p = `r format.pval(wilcox_test$p.value, digits = 3)` < 0.05$, we reject $H_0$. The rank-biserial effect size is $r = `r round(r_rb, 3)`$, indicating a small effect with Cram students tending toward higher work hours.

**5. Decision:**

Since $p = `r format.pval(wilcox_test$p.value, digits = 3)` < 0.05$, we reject $H_0$: Cram students report significantly higher weekly work hours. Ties at zero reduce the precision of the rank-based test, though the large sample size still supports the conclusion. As this is observational data, the result reflects association, not causation, and unmeasured confounders (e.g., course load, financial need) remain possible.


## RQ2: Multitasking and cramming

**Research Question:** Is multitasking during lectures associated with cramming before assessments?

Our client, a university learning-support team, wants to distinguish a lecture-engagement problem from a broader time-management one. Divided attention during study has been linked to weaker academic outcomes (Junco & Cotten, 2012), so multitasking is unlikely to be a neutral habit. If it also travels with cramming, the two may be one behavioural pattern rather than two, which we test with a chi-squared test of independence.

**Exploratory data analysis:**

Rows are dropped only for missing `assess` or `multitask`; the `work_hrs` threshold is not applied here, as neither variable involves paid employment.

```{r}
#| label: rq2-setup
rq2_data <- df %>%
  select(assess, multitask) %>%
  drop_na(assess, multitask) %>%
  mutate(is_cram = factor(
    if_else(assess == "Cram", "Yes", "No"),
    levels = c("No", "Yes")

cram_tab <- table(rq2_data$is_cram, rq2_data$multitask)
chi_test <- chisq.test(cram_tab, correct = FALSE)

chi_statistic <- unname(chi_test$statistic)
chi_df        <- unname(chi_test$parameter)

cramers_v     <- sqrt(chi_statistic / n_total)

yes_counts   <- cram_tab[c("Yes", "No"), "Yes"]

pct_cram     <- 100 * unname(prop_test$estimate[1])
pct_notcram  <- 100 * unname(prop_test$estimate[2])
diff_ci      <- 100 * prop_test$conf.int

by_assess <- rq2_data %>%
  count(assess, multitask) %>%
  group_by(assess) %>%
  mutate(prop = 100 * n / sum(n)) %>%
  filter(multitask == "Yes")
pct_imm  <- by_assess$prop[by_assess$assess == "Immediately"]
pct_grad <- by_assess$prop[by_assess$assess == "Gradually"]
```

**1. Hypotheses:** $H_0$: multitasking is independent of cramming among DATA2x02 students, versus $H_1$: the two are not independent.

**2. Assumptions:** Observations are independent (one response per student) and every expected cell count must be at least 5. The minimum is `r sprintf("%.1f", min_expected)` (@tbl-rq2-expected), so the chi-squared approximation is valid and no continuity correction is applied; had any count fallen below 5, Fisher's exact test would be used instead.

```{r}

```

**3. Test statistic:** $$T=\sum_{i,j}\frac{(O_{ij}-E_{ij})^2}{E_{ij}} \sim \chi^2_{`r chi_df`} \text{ under } H_0$$ The observed value is $t_0 = `r sprintf("%.2f", chi_statistic)`$.

```{r}
#| label: rq2-test
chi_test
```

**4. P-value:** $P(\chi^2_{`r chi_df`} \geq `r sprintf("%.2f", chi_statistic)`) = `r signif(chi_p, 3)`$. Cramér's $V = `r sprintf("%.2f", cramers_v)`$ ($n = `r n_total`$), and the 95% CI for the difference in multitasking rates is `r sprintf("%.1f", diff_ci[1])` to `r sprintf("%.1f", diff_ci[2])` percentage points.

**5. Decision:** Reject $H_0$ ($p < 0.001$): students who cram are considerably more likely to multitask. The effect is modest, so multitasking is one correlate of cramming rather than a defining feature. As a self-selected, self-reported survey, "cram" and "multitask" may be interpreted inconsistently, and the association does not imply causation — overall workload could drive both.

```{r}
#| label: rq3-permutation-test

rq3_data <- df_rq3 %>%
  filter(!is.na(work_hrs), !is.na(multitask)) %>%
  mutate(multitask = factor(multitask, levels = c("No", "Yes")))

welch_stat <- function(hours, group) {
  hours_yes <- hours[group == "Yes"]
  hours_no  <- hours[group == "No"]

  (mean(hours_yes) - mean(hours_no)) /
    sqrt(var(hours_yes) / length(hours_yes) +
           var(hours_no) / length(hours_no))
}

mean_yes <- mean(rq3_data$work_hrs[rq3_data$multitask == "Yes"])
mean_no  <- mean(rq3_data$work_hrs[rq3_data$multitask == "No"])
mean_difference <- mean_yes - mean_no
t_observed <- welch_stat(rq3_data$work_hrs, rq3_data$multitask)

set.seed(2002)
B <- 10000

t_permuted <- replicate(
  B,
  welch_stat(
    rq3_data$work_hrs,
    sample(rq3_data$multitask, replace = FALSE)
  )
)

n_yes <- sum(rq3_data$multitask == "Yes")
n_no  <- sum(rq3_data$multitask == "No")
sd_yes <- sd(rq3_data$work_hrs[rq3_data$multitask == "Yes"])
sd_no  <- sd(rq3_data$work_hrs[rq3_data$multitask == "No"])
pooled_sd <- sqrt(
  ((n_yes - 1) * sd_yes^2 + (n_no - 1) * sd_no^2) /
    (n_yes + n_no - 2)
)
cohens_d <- mean_difference / pooled_sd
```

```{r}
#| label: fig-rq3-permutation
#| fig-cap: "Permutation null distribution of the Welch t-statistic. Dashed red lines indicate the observed cut-offs at plus and minus the absolute observed statistic."

tibble(t_permuted = t_permuted) %>%
  ggplot(aes(x = t_permuted)) +
  geom_histogram(
    bins = 45,
    fill = "#8ECAE6",
    colour = "white"
  ) +
  geom_vline(
    xintercept = c(-abs(t_observed), abs(t_observed)),
```

The two-sided permutation p-value is the proportion of simulated statistics at
least as extreme as the observed statistic:

```{r}
#| label: rq3-p-value

extreme_count <- sum(abs(t_permuted) >= abs(t_observed))

# Plus-one correction for a Monte Carlo permutation p-value
p_permutation <- (extreme_count + 1) / (B + 1)

tibble(
  extreme_permutations = extreme_count,
  total_permutations = B,
  permutation_p_value = p_permutation,
  cohens_d = cohens_d
) %>%
  knitr::kable(
    format = "html",
    digits = c(0, 0, 4, 2),
    col.names = c(
      "Extreme permutations",
      "Total permutations",
      "Permutation p-value",
      "Cohen's d"
    ),
    align = c("c", "c", "c", "c"),
    table.attr = 'class="table table-bordered table-striped" style="width: auto; margin-left: auto; margin-right: auto;"'
  )
```

**1. Hypotheses:** Let $\mu_Y$ and $\mu_N$ be the population mean weekly paid-employment hours for students who do and do not multitask, respectively. $H_0: \mu_Y - \mu_N = 0$ versus $H_1: \mu_Y - \mu_N \neq 0$.

**2. Assumptions:** Student responses are treated as independent, and the multitasking labels are exchangeable under $H_0$. Normality is unnecessary, although a mean-based statistic remains sensitive to large values.

**3. Test statistic:** $T=(\bar X_Y-\bar X_N)/\sqrt{S_Y^2/n_Y+S_N^2/n_N}$. The observed difference is `r sprintf("%.2f", mean_difference)` hours per week and $t_0=`r sprintf("%.3f", t_observed)`$.

**4. Permutation procedure:** With `set.seed(2002)`, the Yes/No labels were shuffled $B=10{,}000$ times while employment hours were fixed. The Welch statistic was recalculated to form @fig-rq3-permutation.

**5. P-value:** For the two-sided test, permutations satisfying $|T_b^*|\geq|t_0|$ were counted. The plus-one estimate is $p_{\mathrm{perm}}=`r sprintf("%.4f", p_permutation)`$.

**6. Decision:** Since $p = `r sprintf("%.4f", p_permutation)` < 0.05$ (the p-value uses the plus-one correction of Phipson & Smyth, 2010), we reject $H_0$. There is evidence that mean employment hours differ by multitasking status; multitasking students worked `r sprintf("%.2f", mean_difference)` more hours per week on average in this sample. However, Cohen's $d=`r sprintf("%.2f", cohens_d)`$ indicates a small effect, so its practical importance is limited. Both variables are self-reported and confounding may remain. As this is an observational survey of students, the result cannot establish causation or automatically generalise to others.


# Conclusion

Overall, the three analyses show consistent links between students’ employment commitments and study behaviours. Students who crammed reported significantly higher weekly paid-employment hours, while multitasking was associated with both cramming and higher employment hours. However, the observed effects were modest, suggesting these factors are related but not decisive.

These findings may help the teaching team recognise how students’ external commitments and study habits interact, particularly when considering cramming and lecture multitasking.

However, the survey is observational and relies on self-reported data, limiting causal interpretation. The 70-hour cleaning threshold and categorisation of preparation styles may also affect results. Potential confounding factors, such as workload or other commitments, and voluntary sampling may limit generalisability. Therefore, the findings should be interpreted as associations rather than evidence of causation.
